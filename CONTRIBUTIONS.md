# ANGE CAFE
## Team Contributions

**Project Title:** Restaurant Ordering and Menu Management System for Ange Cafe – UST Angelicum College

**Institution:** UST Angelicum College

**Program:** Bachelor of Science in Information Technology

## 1. Project Members and Responsibilities

### Maxene Garcia
**Role:** Project Foundation, Database, and Menu Management

Responsibilities:
- Established the ASP.NET Core Web API project structure.
- Configured the SQL Server database and Entity Framework Core.
- Developed the database context, models, and migrations.
- Implemented the Category and Menu Item management features.
- Developed the customer menu interface.
- Developed the administrator menu management interface.
- Integrated the Repository and Service Pattern for menu-related operations.
- Implemented customer order tracking and order history interfaces.

### Althea Onez
**Role:** Staff Order Management

Responsibilities:

- Implemented staff authentication and role-based access.
- Developed the staff interface for viewing and managing customer orders.

- Integrated order management features with the backend API.

### Nichole Pebris
**Role:** Customer Ordering and Checkout

Responsibilities:

## 2. Collaboration and Development

The project was developed collaboratively using Git and GitHub. Each member worked on assigned features using separate development branches.

The team coordinated the integration of frontend interfaces, backend API endpoints, database operations, and authentication features to ensure that the system functions as one application.

## 3. Version Control

GitHub was used for:
- Source code management.
- Branch-based development.
- Committing individual changes.
- Pushing changes to the remote repository.
- Reviewing and merging completed features through pull requests.
